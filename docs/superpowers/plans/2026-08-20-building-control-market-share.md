# Building-Control Market Share Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Windows portable EXE that stores every 2025+ G2B building-control notice in SQLite, attributes final awarded notices by award-date-valid excellent designation, reports year/quarter notice-count market share, and exports an editable native Excel pie chart.

**Architecture:** Keep the existing Next.js standalone server inside the Tauri shell, but replace the hardcoded 22-company competitor path with a dedicated `building-control` domain. Public-data and designation API rows are staged into immutable SQLite generations, and one atomically activated market manifest pins the notice, product, award, designation, classification, and coverage generations visible to reports. A pure report service supplies both the UI and a typed Tauri Rust workbook command. The release is blocked until live API contract probes prove result grain, product-code precedence and recall, representative winner identity, pagination, and historical designation status coverage.

**Tech Stack:** TypeScript 5.7, Next.js 15, React 19, Zod, better-sqlite3, Drizzle schema declarations, Vitest, Recharts 3.10.1, Tauri 2, Rust 1.95, rust_xlsxwriter 0.98.2, tauri-plugin-dialog 2.7.2, serde 1.0.229, serde_json 1.0.151, Playwright 1.62.1.
