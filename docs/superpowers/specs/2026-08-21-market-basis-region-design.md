# 시장점유율 기준 및 지역 필터 설계

## 목표

기존 시장점유율 화면에 `공고 기준/계약 기준`과 `전국/부산` 선택을 추가하고, 동일 조건으로 화면과 엑셀을 생성한다.

## 집계 기준

- 공고 기준: 최종 낙찰일 기준으로 공고 1건을 1건으로 집계한다.
- 계약 기준: 계약체결일 기준으로 계약 1건을 1건으로 집계한다.
- 부산: 수요기관명에 대소문자 구분 없이 `부산`이 포함된 행이다.
- 전국: 지역 필터를 적용하지 않는다.
- 업체 분류는 기존과 동일하게 낙찰/계약 당시 지정 유효기간을 적용하여 22개 우수업체, `조달우수X`, 협동조합으로 나눈다.

## 데이터

- `market_awards`에 공고명, 수요기관, 지역을 추가한다.
- `market_contracts`를 추가하여 계약번호, 계약명, 계약일, 업체, 금액, 수요기관, 지역, 공고번호, URL을 저장한다.
- 동기화 성공 시 두 데이터셋을 각각 교체하고, 실패 시 이전 데이터를 유지한다.
- 계약은 표준계약 및 제3자단가계약 원천을 사용한다. 공고 연계 행은 대상 품목번호를 우선하고, 공고번호가 없는 행은 계약/품목명에 `빌딩자동제어`가 포함된 경우만 포함한다.

## UI 및 엑셀

- 상단에 기준 선택과 지역 선택 segmented control을 추가한다.
- 보고서 API와 엑셀 API는 `basis=award|contract`, `region=all|busan`을 받는다.
- 엑셀 상세 시트는 기준, 지역, 공고명/계약명, 날짜, 공고번호/계약번호, 업체명, 사업자번호, 금액, 수요기관, URL을 포함한다.

## 검증

- 집계 순수 함수의 공고/계약 및 부산 필터 테스트만 추가한다.
- Next 빌드와 포터블 패키징을 확인한다. 전체 API 장시간 재수집 테스트는 반복하지 않는다.
