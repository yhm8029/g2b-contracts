# 지역 확대 및 편집 가능한 차트 설계

## 범위

- 지역 선택을 전국, 수도권(서울/경기), 부산, 충남, 충북, 전남, 전북, 경남, 경북, 강원, 제주, 인천, 대구, 대전, 광주, 울산, 세종으로 확대한다.
- 수요기관 원문을 하나의 공통 분류기로 판정한다. `광주광역시`와 `경기도 광주시`처럼 중복되는 지명은 광역자치단체의 정식 명칭을 우선한다.
- 기존 SQLite의 단순 `부산/기타` 값에 의존하지 않고 보고서와 Excel에서 수요기관 원문을 다시 분류한다. 새로 저장하는 행에는 새 지역명을 기록한다.
- `우수조달물품`과 `제3자단가계약`이 함께 포함된 나라장터 공고는 마스터 단가계약으로 보고 저장, 보고서, Excel에서 제외한다.
- Excel 원형 그래프는 PNG가 아니라 업체명 셀과 건수 셀을 참조하는 Excel 네이티브 차트로 만든다. 사용자는 Excel에서 제목, 색상, 범례, 레이블, 데이터 범위를 수정할 수 있어야 한다.
- 통합 기준에서 나라장터 공고와 종합쇼핑몰 행의 정규화한 내역명, 금액, 사업자번호, 수요기관이 모두 같으면 동일 건으로 본다. 나라장터 공고를 대표 행으로 남기고 종합쇼핑몰 행을 제외한다. 각 단독 기준에서는 원본을 유지한다.

## UI

지역 종류가 많으므로 기존 두 버튼을 하나의 드롭다운으로 교체한다. 선택한 지역명은 화면 부제, 조회 지역 지표, Excel 파일명과 본문에 동일하게 사용한다.

## 검증

- 대표 수요기관명을 이용해 모든 지역 분류와 경기 광주/광주광역시 경계를 확인한다.
- 제3자단가 우수조달 공고가 기존 DB에 있어도 조회 결과에서 제외되는지 확인한다.
- 통합 기준의 교차 원천 중복은 나라장터 행 하나만 남고 단독 기준에는 영향을 주지 않는지 확인한다.
- 생성 XLSX 안에 네이티브 차트 XML과 업체명/건수 셀 참조가 있는지 확인한다.
