# 시장점유율 엑셀 파일명 설계

## 규칙

- 파일명은 `<기준>_<지역>_<기간>.xlsx` 형식으로 만든다.
- 기준은 `나라장터`, `종합쇼핑몰`, `통합` 중 하나다.
- 지역은 `전국`, `부산` 중 하나다.
- 연간은 `2026연간`, 분기는 `2026년3분기` 형식을 사용한다.
- 한글 파일명은 RFC 5987의 `filename*` 다운로드 헤더로 전달한다.

## 예시

- `나라장터_부산_2026연간.xlsx`
- `통합_전국_2026년3분기.xlsx`

## 검증

파일명 생성 함수의 연간·분기 사례를 단위 테스트하고, 배포된 EXE의 다운로드 응답 헤더를 확인한다.
