# 통합 대표건·지역·API 할당량 설계

## 목표

- 동일 사업의 나라장터 낙찰과 종합쇼핑몰 계약은 원본 DB에 각각 보존한다.
- 통합 집계는 연계된 종합쇼핑몰 계약이 있으면 계약일·계약번호·실제 계약금액을 대표값으로 사용하고, 없으면 나라장터 낙찰을 사용한다.
- 통합 Excel에는 연계된 종합쇼핑몰 계약번호와 계약일을 함께 표시한다.
- 광역지명이 없는 기관명/공고명의 주요 도시명을 해당 지역으로 분류한다.
- 공공데이터 일일 할당량 소진을 일반 동기화 실패와 구분한다.

## 동작

1. 공고명, 사업자번호, 수요기관을 정규화하고 나라장터 낙찰 뒤 180일 이내의 가장 가까운 쇼핑몰 계약을 일대일로 연결한다. 금액 차이는 연결을 막지 않는다.
2. 연결되면 통합 대표일·대표번호·집계금액은 종합쇼핑몰 값을 쓴다. 연결되지 않은 나라장터 공고는 낙찰 값을 쓴다.
3. 통합 Excel에는 나라장터/쇼핑몰의 번호·날짜·금액을 각각 보존한다.
4. 창원·김해·진주 등 광역지명이 없는 주요 도시명은 기존 지역 코드로 매핑한다. 기관명이 특정되지 않을 때만 제목을 보조 근거로 사용한다.
5. HTTP 429 또는 공급자 메시지의 일일 트래픽/요청 한도 표현을 `quota_exhausted`로 분류한다. UI는 다음 초기화 시각(한국시간 00:00 이후)을 안내하고 기존 DB를 유지한다.

## 보존 규칙

- 출처별 화면은 원본 사실을 그대로 조회한다.
- 통합 화면/Excel만 연결된 쇼핑몰 행을 중복 제외한다.
- 업체·수요기관이 다르면 자동 연결하지 않는다. 금액 차이는 양쪽 금액 열로 감사할 수 있게 보존한다.
