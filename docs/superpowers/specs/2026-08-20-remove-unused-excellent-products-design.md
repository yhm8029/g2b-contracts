# 미사용 조달우수제품 기능 제거 설계

## 목적

현재 EXE가 사용하는 경쟁사 영업 성과 화면은 고정된 22개 경쟁사와 세부품명번호 `3912180101`을 기준으로 계약을 집계한다. 이 경로와 연결되지 않은 별도 조달우수제품 CSV 스냅샷 기능을 제거해 코드와 운영 절차를 단순화한다.

## 제거 범위

- `/excellent-products` 별도 화면과 화면 컴포넌트
- `/api/excellent-products/building-control` 관련 조회, 동기화, 내보내기 API
- `UI-ADOSAA-005R` CSV 파서, 스냅샷 저장소, 업체 보강 로직 및 전용 형식
- `excellent-products:import`, `excellent-products:sync` CLI와 실행 스크립트
- 위 기능만 검증하는 테스트 및 현재 기능으로 안내하는 README 문구
- 홈 화면에서 별도 조달우수제품 화면으로 연결하는 링크

## 유지 범위

- `/competitors` 경쟁사 영업 성과 화면
- 고정 22개 경쟁사 등록부와 지정 시작·종료일
- 세부품명번호 `3912180101` 계약 판정
- 표준계약 및 제3자단가 납품 조회, 로컬 캐시, 기간별 집계, 엑셀 내보내기
- Tauri EXE 실행과 로컬 서버
- 다른 기능이 공유하는 DB 테이블과 유틸리티

## 데이터 안전

기존 SQLite 파일에 이미 생성된 우수제품 관련 테이블이나 행은 마이그레이션으로 삭제하지 않는다. 새 코드에서 참조하지 않을 뿐이며, 사용자의 기존 데이터 파일을 파괴적으로 변경하지 않는다. 공유 여부가 불명확한 DB 구조는 유지한다.

## 검증

1. 제거 대상 모듈을 참조하는 import, 경로, package script가 남지 않아야 한다.
2. 전체 Vitest 테스트가 통과해야 한다.
3. Next.js 프로덕션 빌드가 통과해야 한다.
4. Tauri 소스가 계속 `/competitors`를 시작 화면으로 사용해야 한다.
5. 경쟁사 집계 핵심 테스트와 엑셀 내보내기 테스트가 유지되어야 한다.
